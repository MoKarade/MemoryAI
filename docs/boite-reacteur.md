# Boîte locale du Réacteur

PR brouillon permanente, ne pas fusionner ni fermer (MoKarade/.github#772).
Tant que le secret `REVEIL_TOKEN` n'est pas posé sur ce dépôt, le Réacteur y commente une ligne `RÉACTEUR : …` (identifiants seulement) quand une tâche devient prenable ou demande une preuve. Le fil du dépôt, abonné à la PR, est réveillé par chaque commentaire.
Avec le jeton, le réveil passe par la boîte d'app-template comme pour les autres dépôts.
